# 버스 회차 대기 예측 (bus-layover-prediction)

버스가 회차지에서 얼마나, 언제 대기하는지를 기록하기 위한 수집 스크립트입니다. 기본 대상은 화성시 H2번 버스(회차지: 병점역후문)이며, `collect.py` 상단의 노선 설정을 바꾸면 다른 경기도 노선도 수집할 수 있습니다.
2026 데이터+AI 혁신 챌린지 데이터 문제해결 부문(데이터레시피 제안) 참가를 위해 만들었습니다.

## 문제 정의

버스 도착예정시간은 현재 위치와 남은 거리를 기준으로 계산되기 때문에, 회차지에서의 대기 시간이 반영되지 않습니다.
그래서 회차지 다음 정류장 이용자는 "15분 후 도착"을 보고 기다리다가 버스가 회차 대기에 들어가면 안내가 사라지거나 크게 늦어지는 일을 겪습니다.
회차 대기는 정해진 장소와 시간대에 반복되거나(휴식), 앞차와의 배차 간격으로 결정되므로(간격 조정) 데이터로 미리 예측할 수 있습니다.

## 데이터 출처

공공데이터포털에서 제공하는 경기도 버스정보 Open API (v2)를 사용합니다.

| API | 용도 |
|---|---|
| 경기도_버스위치정보 조회 | 차량별 현재 정류장 위치 (회차 대기시간 계산) |
| 경기도_버스도착정보 조회 | 기존 도착예정시간 (보정 전후 비교 기준) |
| 경기도_버스노선 조회 | 노선 정보·배차 간격, 경유 정류소 목록 (회차 지점 확인) |

## 사용법

1. 패키지 설치
   ```
   pip install -r requirements.txt
   ```
2. 인증키 설정: `.env.example`을 복사해 `.env`로 이름을 바꾸고, `BUS_API_KEY=` 뒤에 공공데이터포털 **일반 인증키(Decoding)** 를 넣습니다.
3. 작동 확인
   ```
   python collect.py --test
   ```
4. 수집 시작 (중지는 Ctrl+C, 다시 실행하면 이어서 저장)
   ```
   python collect.py
   ```

## 수집 방식

- 90초 간격으로 수집 (하루 약 800회, 개발계정 일일 1,000회 제한 안쪽)
- 운행이 없는 01:00~04:59는 수집하지 않음
- 네트워크 오류가 나도 멈추지 않고 다음 회차에 다시 시도

## 저장 파일 (`data/`, 저장소에는 올라가지 않음)

| 파일 | 내용 |
|---|---|
| `route_info.json` | 노선 정보 (배차 간격, 첫차·막차 등) |
| `stations.csv` | 경유 정류소 목록 (순서, 회차 여부) |
| `locations.csv` | 수집 시각별 차량 위치 |
| `arrivals.csv` | 회차지 다음 정류장의 도착 예측 |
| `collect.log` | 실행 기록 |

## 한계

위치 API는 GPS 좌표가 아니라 정류장 단위 위치를 제공하므로, 회차지 출발 시각은 수집 간격(90초)만큼의 오차를 가집니다.
